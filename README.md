# Dragonfic

MVP de uma plataforma privada/independente para fanfics, com estética rosa + escura.

## Rodar
1. `npm install`
2. copie `.env.example` para `.env.local` quando conectar o Supabase
3. `npm run dev`

## Próxima etapa
Conectar Supabase para autenticação simples (username + senha), perfis, histórias, capítulos, progresso por trecho, comentários ancorados em seleção, curtidas, respostas, enquetes, feed e uploads de capas/avatares.
